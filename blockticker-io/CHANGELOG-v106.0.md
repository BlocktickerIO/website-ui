# BlockTicker v106.0.0 — Price Correlation Heatmap

**Release date:** April 2026
**Type:** Feature release (additive, no breaking changes)
**Upgrade path:** Drop-in over v105.0.0

---

## Overview

`[bt_correlation_heatmap]` renders a colour-coded n×n matrix showing the
Pearson correlation of daily log-returns between any combination of crypto
and forex assets tracked in `wp_bt_price_history`. No external JS library —
pure PHP computation, pure HTML/CSS output.

---

## New: `includes/class-correlation.php`

One new class `BT_Correlation` (~330 lines).

### Algorithm

1. Reads daily closing prices for each requested symbol via
   `BT_Database::get_price_history( $sym, $days, '1d' )`.
2. Aligns all series to their common trading dates.
3. Computes **daily log-returns**: `ln( P_t / P_{t-1} )`.
4. Computes **Pearson correlation** for every pair using the standard
   `Σ(dx·dy) / √(Σdx²·Σdy²)` formula — returns a value in [-1.0, +1.0].
5. Builds a symmetric n×n matrix (1.0 on the diagonal).
6. Caches the result as a transient for 6 hours.

Log-returns are used instead of raw prices because they are stationary
(prices drift, returns don't), making the correlation coefficient more
statistically meaningful over multi-week windows.

### Cache

- Transient key: `bt_corr_{md5(symbols_days)}`
- TTL: 6 hours
- Busted on `bt_refresh_prices` action (price cron)
- Manual bust via `BT_Correlation::bust_cache()` (bulk DELETE of `bt_corr_*` transients)

### Shortcode: `[bt_correlation_heatmap]`

```
[bt_correlation_heatmap symbols="BTC,ETH,SOL,EUR/USD,GBP/USD,XAU"
                         days="30" title="Price Correlation (30d)"
                         colorscale="rg" show_values="1" min_r="0"]
```

**Attributes:**

| Attribute | Default | Description |
|-----------|---------|-------------|
| `symbols` | BTC,ETH,SOL,EUR/USD,GBP/USD,XAU | Comma-separated symbols (max 12) |
| `days` | 30 | Look-back window 7–365 days |
| `title` | "Price Correlation Heatmap" | Card heading; empty to hide |
| `colorscale` | `rg` | `rg` = red→grey→green; `bwr` = blue→white→red |
| `show_values` | 1 | Show numeric coefficient in each cell |
| `min_r` | 0 | Cells with `|r| < min_r` rendered grey (e.g. `0.2` to highlight strong pairs) |

**Rendered layout:**

- Column and row headers with symbol labels
- Each cell coloured by coefficient strength:
  - `rg` scale: green opacity scales with positive r; red opacity with negative r
  - `bwr` scale: blue→white→red (conventional academic style)
- Cells dim on hover with outline focus ring (keyboard accessible)
- `title` attribute on each cell for screen readers and tooltip
- Colour legend bar beneath the matrix with –1.0 / 0 / +1.0 labels
- Methodology footnote: "Pearson correlation of daily log-returns…"
- Horizontally scrollable on narrow viewports

**Text contrast:** white text for strong correlations (|r| > 0.5), grey for weak.

**Maximum 12 symbols** — the matrix is n² cells; beyond 12 it becomes unwieldy
on mobile.

**Insufficient data** — if a symbol has fewer than 5 daily closes in the window,
it is listed in a warning but still included in the matrix with null cells.

### REST endpoint: `GET /wp-json/blockticker/v1/correlation`

Parameters: `symbols` (comma-separated, default 6 assets), `days` (7–365, default 30).

Response:
```json
{
  "data": {
    "symbols": ["BTC", "ETH", "EUR/USD"],
    "matrix":  [[1.0, 0.87, -0.12], [0.87, 1.0, -0.09], [-0.12, -0.09, 1.0]],
    "dates":   29,
    "warning": null
  },
  "meta": { "generated_at": "2026-04-21T14:00:00+00:00", "days": 30 },
  "source": "BlockTicker price correlation (Pearson, daily log-returns)"
}
```

## Usage examples

**Default 6-asset matrix, 30-day window:**
```
[bt_correlation_heatmap]
```

**Crypto-only, 90-day window, highlight strong pairs:**
```
[bt_correlation_heatmap symbols="BTC,ETH,SOL,BNB,AVAX,MATIC" days="90" min_r="0.4"]
```

**Forex pairs, blue-white-red scale:**
```
[bt_correlation_heatmap symbols="EUR/USD,GBP/USD,USD/JPY,AUD/USD,USD/CHF" days="60" colorscale="bwr"]
```

**Cross-asset (crypto + forex + gold):**
```
[bt_correlation_heatmap symbols="BTC,ETH,EUR/USD,GBP/USD,XAU,XAG" days="30"]
```
